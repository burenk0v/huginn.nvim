# Huginn.nvim

Opinionated Neovim environment for SDETs.

Huginn keeps the editor implementation in Lua and the SDET team's project conventions in YAML.

> Think. Test. Automate.

## Status

Early development. The initial architecture is being built around Python, Poetry, Ruff, ty, pytest, debugpy, and OpenAI-compatible AI tooling.
